# ORCHESTRA-OS 1.0.1 research source release

This release publishes the reviewed 1.0.1-rc1 hardening source from upstream
commit `4c1fb8a`, with publication cleanup and consistent public metadata.
It retains the five canonical actions and ABI layouts. Changes cover bounded
policy publication and abort deadlines, rejection of blocking policy inputs,
saturating telemetry deadlines, explicit artifact identity validation, and
safe release archive verification.

The release assets contain source archives, SHA-256 checksums, a source manifest,
and validation logs. No native binary packages, signatures, or hosted build
attestations are claimed. The legacy v1.0.0 native-package workflow is manual;
it does not publish or replace this source release.

Validate extracted source with `make`, `make check`, `make test`, and
`python3 scripts/check-doc-links.py`. Use `sha256sum -c SHA256SUMS` in the
download directory before extraction. The validation report records actual
outcomes and retains failures.

Validation is non-privileged and offline. No scheduler attachment, new
performance experiment, stress campaign, or deployment certification is
performed for publication. Kernel verifier acceptance, effective THROTTLE,
concurrency, RT guarantees, and target-specific runtime behavior remain open
gates. Historical experimental records remain available in the repository.
