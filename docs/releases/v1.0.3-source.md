# ORCHESTRA-OS 1.0.3 paper companion source release

This documentation and evidence release adds a paper-oriented README,
reproduction guide, claim–evidence map, checksummed historical data, and
folder indexes. The submitted IEEE Access manuscript is identified separately
from the earlier simulation dataset. Manuscript submission is not publication.

Implementation, tests, and operational scripts match 1.0.2. Offline build and
regression evidence is carried forward from the [1.0.1 validation report](../validation/PUBLIC_RELEASE_1_0_1.md);
no new kernel runtime or performance campaign is performed. Documentation,
archive contents, numerical summaries, byte-preserved data checksums, and
publication hygiene are checked for this release.

The copied Linux source headers under a historical campaign are removed from
the current tree. Their [inventory](../history/RETIRED_GENERATED_FILES.md)
retains the prior Git revision and file hashes; logs and results are preserved.
The source archives intentionally omit bulk historical artifacts, which remain
in the Git repository. The compact `docs/paper/data/` tables are included.

See the [paper reproduction guide](../paper/REPRODUCIBILITY.md) for the boundary
between data analysis, current-source tests, and exact hardware replication.
No universal speedup, advantage over cgroup control, or deployment readiness
is established. Downloads include source ZIP/TAR.GZ, a manifest, checksums,
and validation reports. No native packages or hosted attestations are claimed.
