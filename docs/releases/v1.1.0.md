# v1.1.0 Linux packages and paper companion

This release synchronizes the public paper companion layout and adds native
DEB, RPM, APK and Arch packages. The build matrix has 35 targets: Ubuntu
22.04/24.04/26.04, Debian 12/13, Kali rolling, Fedora 43/44, Rocky 9/10,
AlmaLinux 9/10, Amazon Linux 2023, Alpine 3.23/3.24, openSUSE Leap 16 and
Tumbleweed on x86_64 and ARM64; Arch on x86_64.

Only targets marked PASS in release PLATFORM_RESULTS.md receive packages.
Pinned OCI images establish the build environment. Full source regressions
run on both architectures; each native target runs build checks and package
installation, executable, removal and configuration-preservation smoke tests.
Failed logs remain available. Rolling distributions are tested at build time.

Native packages contain userspace tools and bridge/loader, not a universal
kernel BPF object. Installation leaves scheduler activation disabled.
Kernel runtime ownership, actions, safety and performance require separate
machine-specific validation. Existing paper measurements are archived results.

Download a package matching both distribution and CPU architecture from the
[release](https://github.com/Aether-0/ORCHESTRA-OS-final/releases/latest).
Verify SHA256SUMS and build provenance. Install DEBs using apt, RPMs using the
distro package manager, APKs using apk (local unsigned package requires
--allow-untrusted), and Arch packages using pacman -U. SPDX files identify
package artifact checksums; they do not enumerate every transitive dependency.
