# v1.1.1 publication polish

The root directory now contains standard project entry points. Status,
security assessments and work packages live under docs; older final reports
live under docs/history. Scheduler source and executable tests are unchanged.

## Release downloads

| Download | Purpose |
| --- | --- |
| Distribution-matched DEB/RPM/APK/Arch package | Install userspace tools and bridge/loader |
| Source ZIP or TAR.GZ | Build or review maintained source and compact paper evidence |
| SHA256SUMS | Verify each downloaded asset |
| PLATFORM_RESULTS.md | Read the distro/architecture matrix and download guidance |
| RELEASE_MANIFEST.json | Check source identity, package mapping and asset hashes |
| build-evidence.zip | Review original logs and detailed results, with internal checksums |
| package-sboms.zip | Review per-package SPDX records, with internal checksums |

With all 35 targets passing, this layout has 42 downloadable assets, compared
with 146 in v1.1.0. Evidence is bundled, not discarded. Existing releases and
tags remain unchanged. Each outer download receives GitHub build provenance;
ZIP checksums cover their complete contents, and inner checksum manifests
allow verification after extraction.

The [native matrix and dependency policy](v1.1.0.md) remain in effect.
Installation does not activate sched_ext. Packages ship userspace tooling;
kernel BPF artifacts still need target-matched builds and runtime validation.
