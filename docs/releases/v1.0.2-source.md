# ORCHESTRA-OS 1.0.2 source publication cleanup

This release removes coding-agent instruction files from the public source tree
and source downloads. The scheduler implementation, build scripts, and tests
are unchanged from version 1.0.1 (commit
`795087748daae3cab3ebe5671ea12082d1917759`).

Build, unit, integration, and security results are carried forward from the
[1.0.1 validation report](../validation/PUBLIC_RELEASE_1_0_1.md). This cleanup
is checked with the existing documentation-link and publication-security tools,
a whitespace check, and inspection of the release archive contents. It does
not introduce new runtime or performance evidence.

Download source TAR.GZ or ZIP, SHA256SUMS, a release manifest, and validation
reports from the latest release. Verify with `sha256sum -c SHA256SUMS` before
extraction. The [1.0.1 scope and limitations](v1.0.1-source.md) remain applicable.
Historical research reports, raw evidence, and earlier Git revisions are
retained for provenance.
