# Support

This project is a research prototype. Open a GitHub issue for reproducible
userspace, packaging, documentation, or build problems. Include the release
version, distribution, architecture, command, and the complete error output.

For security vulnerabilities, use the private GitHub security advisory channel
described in .github/SECURITY.md; do not post secrets or kernel dumps in a
public issue.

The sched_ext path is target-specific and opt-in. Issues that depend on a
kernel not exposing the required sched_ext/BTF/libbpf interfaces may be
environment limitations rather than product defects.
